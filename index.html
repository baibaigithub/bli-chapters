bli-chapters 隐私政策

更新日期：2026 年 10 月 18 日。bli-chapters 是独立的第三方 Chrome 扩展， 与哔哩哔哩和 DeepSeek 无关联。

处理的数据与目的

扩展只在 www.bilibili.com/video/* 页面运行。为了识别当前视频及分 P， 它向 B 站接口请求视频标识、分 P 信息和字幕轨。浏览器可能随这些请求发送现有的 B 站 Cookie。点击“检查字幕”只在本机提取字幕条数、时间范围等诊断信息， 不向 DeepSeek 发送字幕。

用户在设置页阅读说明、勾选同意并保存自己的 DeepSeek API Key 后，扩展会在打开 有字幕的视频页时自动把当前分 P 的字幕文本、时间戳和视频标题直接发送到 DeepSeek API，以生成章节标题、要点和时间跳转。API Key 随 HTTPS 请求作为认证信息 发送给 DeepSeek。使用 DeepSeek 可能产生用户账户费用；DeepSeek 如何处理请求数据 以其自身政策为准。

本地保存与删除

API Key、同意状态和生成的大纲保存在本机的 Chrome 扩展本地存储，不通过 Chrome 同步。完整字幕仅在生成过程的内存中使用，不长期保存。扩展没有开发者中转服务器、 广告分析服务，也不出售数据。本机存储不等于加密保险箱；能访问设备或浏览器配置的 人可能读取这些数据。

用户可以在扩展设置页删除 API Key 或清空大纲缓存；移除扩展也会删除对应的扩展存储。 关闭同意后不再自动分析，既有大纲缓存需单独清空。

权限范围

扩展仅请求 B 站视频页脚本注入、B 站视频与字幕接口、字幕 CDN、DeepSeek API 和 Chrome 本地存储所需权限。扩展不下载视频，不识别画面，不处理其他视频平台。
